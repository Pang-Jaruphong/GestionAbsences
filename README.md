## Description du projet
Une application ewb pour gérer les absences des élèves de cours MA-Métier de CPNV
## Fonctionalités
Authentification : connexion sécurisée.
Tableau de bord : vue d'ensemble des absences.

## Technologites utilisées
Frontend : HTML/CSS  
Backend : Node.js avec Express  
Base de données : MySQL, HeidiSQL  
Gestion de paquets : npm

## Installation 
1. Prérequis
Node.js  
npm
MySQL
2. Clonage du projet
git clone https://github.com/Pang-Jaruphong/GestionAbsences.git
3. Configuration du Backend
Allez dans le fichier backend : cd backend  
Installez les dépendances : npm install, npm install express  
Créez le fichier package.json : npm init  
Créez le fichier .env et remplissez vos variables (HOST, USER, PASSWORD, DB NAME)  
Créez le point d'entrée : app.js  
Configurez le script de package.jason : "start":"node app.js"  
Ajoutez dans le script : "type":"module"  
Installez MSQL : npm install mysql2  
Installez node : npm install nodemon  
Installez hash le mot de passe : npm install bcypt  
Lier le backend et frontend : npm install cors
